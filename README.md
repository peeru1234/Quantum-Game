# ⚛️ QUANTUM SINGULARITY — The Quantum Quest

> **"Master the laws of the quantum world before reality collapses."**

![Quantum Singularity](https://img.shields.io/badge/Status-Playable-brightgreen) ![Tech Stack](https://img.shields.io/badge/Tech-React_%7C_Three.js_%7C_R3F_%7C_Vite-00f3ff) ![License](https://img.shields.io/badge/License-MIT-blue)

A 3D First-Person Sci-Fi Educational Quantum Adventure & Puzzle Game built with React 18, Three.js, React Three Fiber, and TailwindCSS.

---

## 🚀 Game Features

- **10-Minute Reactor Collapse Timer**: Real-time survival countdown before the facility collapses.
- **Quantum Mechanics Gameplay**:
  - **Quantum Basis Shift `[Q]`**: Toggle between Computational Basis $|Z\rangle = \{|0\rangle, |1\rangle\}$ and Superposition Basis $|X\rangle = \{|+\rangle, |-\rangle\}$.
  - **Quantum Snapshot `[R]`**: Record and restore exact quantum state vectors.
  - **Superposition Echo `[C]`**: Spawn holographic clone projections.
  - **Reality Fracture `[F]`**: Open spatial rift portals across facility sectors.
  - **Superposition Collapse `[V]`**: Force wave function collapse.
  - **Quantum Dash `[B]`**: Short-range space-time teleportation.
- **What-If Quantum Simulator `[T]`**: Interactive quantum circuit laboratory for manipulating X, H, Z, CNOT gates and measuring wave functions.
- **Quantum Scanner Diagnostic `[G]`**: Holographic target readout revealing qubit state, probabilities, stability, and entanglement status.
- **Explorer Skill Tree `[K]`**: Earn XP from missions to unlock active and passive quantum abilities.
- **6 Major Quantum Worlds**:
  1. Level 1 — Quantum Lab
  2. Level 2 — Superposition City
  3. Level 3 — Entanglement Chamber
  4. Level 4 — Quantum Computer
  5. Level 5 — Quantum Battlefield
  6. Level 6 — Quantum Singularity
- **3D Quantum Enemies & Boss**: Superposition Phantoms, Decoherence Viruses, Entanglement Guardians, and The Quantum Guardian (5-Phase Boss).

## 🎮 Controls

| Key | Action |
| --- | --- |
| **W A S D** | Movement |
| **Mouse / Drag** | Camera Look |
| **Q** | Shift Quantum Basis ($|Z\rangle \leftrightarrow |X\rangle$) |
| **E** | Interact with Machines & Doors |
| **R** | Quantum Snapshot & Restore |
| **C** | Superposition Echo Clone |
| **F** | Reality Fracture Rift Portal |
| **V** | Superposition Collapse |
| **B** | Quantum Dash Teleport |
| **G / Tab** | Toggle Quantum Scanner |
| **T** | Open What-If Quantum Simulator |
| **K** | Open Explorer Skill Tree |

## 🛠️ Quick Start

```bash
# 1. Clone repository
git clone https://github.com/peeru1234/Quantum-Game.git

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build production bundle
npm run build
```
